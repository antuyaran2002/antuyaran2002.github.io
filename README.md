# 柯婧然 Jingran Ke 个人作品集

这是平铺发布版本：全部 77 个文件放在同一个目录，无需构建或安装依赖。包含 15 个项目、完整高清图片、adidas 视频和作品集 PDF。

## 上传与部署

1. 将本目录内的全部文件一起上传至 `antuyaran2002.github.io` 仓库根目录，保留 `.nojekyll`；不要再套一层文件夹。
2. 在仓库 **Settings → Pages** 中启用从 `main` 分支的 `/ (root)` 目录部署。
3. 部署完成后访问 `https://antuyaran2002.github.io/`。

所有资源必须与 `index.html` 同级，请保留文件原名。项目详情使用 `#/项目编号` 路由；中英文切换、悬浮预览、滚动动效、视频播放和 PDF 下载均保留。

本地可使用任意静态文件服务器预览。Google Fonts 字体需要联网；网络不可用时自动使用系统字体。
